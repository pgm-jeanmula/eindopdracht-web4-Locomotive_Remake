# Awwwards Remake – GSAP Driven Website

Dit project is een remake van een awwward-winning website met als doel het **pixel-perfect herbouwen van een pagina**, met een sterke focus op **motion design, scroll-gedreven interactie en clean GSAP code**.

Gekozen referentie:
:contentReference[oaicite:0]{index=0}

---

## Opdrachtomschrijving

Voor deze opdracht moest één volledige pagina van een awwward-winning website worden herbouwd tot een **productieklaar, responsive en motion-gedreven eindresultaat**.

De focus ligt niet op het aantal pagina’s, maar op:
- visuele nauwkeurigheid
- doordachte animaties
- correcte toepassing van GSAP
- performante, begrijpelijke code

De originele content mocht behouden of licht aangepast worden, zolang de **structuur, typografie en motion-logica** van het origineel gerespecteerd blijven.

---

## Motivatie van de gekozen website

De homepage van Locomotive gebruikt scrollen niet louter als navigatie, maar als **verhalend instrument**.  
Content wordt gepind, opgebouwd, getransformeerd en opnieuw losgelaten.

De website is:
- sterk typografisch
- volledig DOM-gedreven
- rijk aan scroll-interactie
- technisch uitdagend zonder afhankelijk te zijn van zware WebGL-oplossingen

Dit maakt de site bijzonder geschikt om **GSAP diepgaand toe te passen** binnen de scope van dit vak.

---

## Technische doelstellingen

Dit project moet aantonen dat ik:

- GSAP **volledig beheers**
- animaties logisch kan structureren met **timelines**
- **ScrollTrigger** correct inzet voor storytelling
- typografie animeerbaar maak zonder leesbaarheid te verliezen
- performante animaties kan bouwen binnen de DOM

---

## Gebruikte technologieën

- **HTML5**
- **CSS3** (moderne units, responsive layout)
- **JavaScript (Vanilla)**
- **GSAP**
  - Core
  - ScrollTrigger
  - SplitText
- **Lenis** (smooth scrolling)

Er wordt bewust **geen gebruik gemaakt van WebGL, ThreeJS of PixiJS**, om de focus te houden op DOM-animaties en GSAP.

## Projectstatus per milestone

### Milestone 1 – Keuze
- Gekozen website: Locomotive homepage
- Technische haalbaarheid en GSAP-focus goedgekeurd

### Milestone 2 – Structuur & voorbereiding
- Analyse van layout, typografie en scroll-logica
- Bepalen van scope (één pagina, storytelling focus)

### Milestone 3 – Alpha versie
- Basislayout uitgewerkt (±90%)
- Hero sectie met intro-animatie
- Scroll-gedreven storytelling section met pin & scrub
- Gebruik van SplitText en stagger

### Final Release (in progress)
- Verdere verfijning van layout en spacing
- Extra scroll-secties
- Micro-interacties
- Mobile optimalisatie
- Performance polish

---

## Belangrijkste GSAP-concepten in dit project

- **Timelines** voor gestructureerde animatie-opbouw
- **Staggering** voor leesbare typografie-animaties
- **ScrollTrigger**
  - pinning van secties
  - scrubbed animations
  - custom scroll-lengtes
- **SplitText** voor woord-gebaseerde animaties
- **Lenis** voor een high-end scrollgevoel
